Manager app · foundation v2 · proposal, values not final

Three columns, one indent.

Every screen is the same three full-height columns: navigation, a header with its list, and the details. The look follows Apple’s desktop conventions: the system font, hairlines instead of boxes, white cards on a warm linen ground, and one accent colour, petrol, for what you can act on. Nothing here changes what a screen contains.

The palette is Linen (the ground), Petrol (the one action colour) and Pale Pink, used only as the selected navigation item: pale pink is also the hue of the failed tint, so it is never a status or a surface. Colour is never the only signal: every status carries a glyph and a word.

Colour from the name · the same name is the same colour on every device and every reload
The rule
  1. Take the name as shown. A person’s display name or a brand’s name; the email only when there is no name. Trim it, normalise it to NFC, lower-case it.
  2. Hash it. FNV-1a, 32 bit, over the name’s UTF-16 code units: start at 0x811c9dc5; for each unit, xor it in, multiply by 0x01000193, keep 32 bits.
  3. Hue = hash mod 360. No random number and nothing stored: the colour is a function of the name.
  4. Colour it. Background hsl(hue S L) and initials hsl(hue S L), with the saturation and lightness of the active theme (table).
  5. Initials. The first letter of the first word and of the last word, upper case. One word gives one letter. For an email, take the part before the @, drop anything after a +, split it on dots, underscores and hyphens, and use the same two letters.

The colour is decoration, never the signal: the initials carry the identity, so two names with near hues cost nothing. Avatar hues overlap the status colours, so an avatar is always a circle or a rounded square with letters, never a capsule with a glyph and a word. People are circles; a brand is a rounded square. The signed-in person’s avatar stands in the navigation, above Sign out, where the email was; the email is its hover text and the avatar’s name is the display name.

Sizes follow macOS text styles (Large Title 26/32, Title 1 22/26, Headline 13). Two judgement calls: body leading is 18 rather than 16 because warning texts run to several lines, and the caption floor is 12 rather than Apple’s 10 so secondary text stays readable on a laptop. Weights used: 400, 500, 600, 700. Tabular figures on for counts and times.
