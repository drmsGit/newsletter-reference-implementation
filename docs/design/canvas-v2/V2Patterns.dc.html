Manager app · screen patterns v2 · wireframes

Every screen is a list and its details.

Same three columns, same places. These wireframes show where each screen’s parts go. They carry region names only: what a screen contains stays with the interview records and ADRs.

Navigation is column 1Always there, collapses to an icon rail when the screen needs the width.
The header lives in the listTitle, count and filters on the list’s own surface. No separate top bar.
Parts that share a function share a placePaging and the history link sit at the foot of the list they belong to.
Actions live in the detailsDocked at the bottom of column 3, on the same ground, as one group.
