# Animatic tools

Scripts that build the animatic from the storyboard. They carry absolute paths of the author's machine: a starting point, not a tool. Scene timings are the `DUR` table in `score.py`; keep it equal to the storyboard's.

**Voice: one switch.** `narrate_tts.py --provider kokoro|openai|elevenlabs --config voice-config.json --out <dir>` reads script A from `VOICEOVER.md`, one file per scene (S08 and S19 per sentence), each fitted into its window, and writes native and 44.1 kHz files plus `report.json`. `tts_providers.py` holds the three providers behind one interface. Copy `voice-config.example.json` to `voice-config.json` and fill it in; it carries no key, and the keys are read only from the environment (`OPENAI_API_KEY`, `ELEVENLABS_API_KEY`).
- **Kokoro** (local, free, the current voice `bf_emma`): needs a Python environment with `kokoro-onnx`, `soundfile` and `numpy`, the two model files (`kokoro-v1.0.onnx`, `voices-v1.0.bin`, from the project's GitHub release `model-files-v1.0`) and Homebrew `espeak-ng` (the pip copy of espeak-ng does not work on this Mac). Acronyms stay as written: the respelling "A I" makes the phonemiser read the A as the article.
- **OpenAI** (`gpt-4o-mini-tts`): takes written instructions, so tone and the end of a question are steered in `voice-direction.json`. No speed setting. Roughly 1.5 cents per minute (a community figure).
- **ElevenLabs**: tone comes from the voice and its settings; `previous_text` and `next_text` carry intonation across lines. Raw PCM back. $0.10 per 1,000 characters on multilingual v2 and v3, EUR 0.05 on Turbo and Flash (Diede's price list).
- **Paid providers only print a dry run** (what would be sent, the characters, the approximate cost) unless `--send` is given; `--only S12,S19` re-reads chosen scenes; lines are cached by a hash of settings, text, direction and neighbours, so a retake pays only for what changed; `--budget-chars` (default 6000) refuses an accidentally large run. **The paid requests follow the providers' public APIs as I know them and have not been tried against the real services:** the first real call should be one short scene with `--only S19 --send`.
- `test_providers.py` proves the request shapes, the decoding, the key handling, the dry run, the cache and the budget guard against a local fake server: no network, no key, no cost.
- `audition.py` renders the same lines in several Kokoro voices.

**ElevenLabs beyond narration.** `elevenlabs_extras.py` has `status` (credits left), `voices`, `sfx` and `music`; the last two spend credits and are a dry run unless `--send` is given. `elevenlabs_test_run.py` is a small, capped listening test (narration of S12 and S19, three sound effects, two music beds; about 860 credits by estimate; `--max-credits` refuses a bigger plan; credits are read before and after). **Keys:** a key is read from the environment or from ONE line of an env file named with `--env-file` (or `env_file` in `voice-config.json`); the program looks for that one name, and the value is never printed or put in an error message. `python tts_providers.py --check ELEVENLABS_API_KEY <env file>` says whether it is found and how long it is. Do not paste a key into a chat or a file in the repository. The free ElevenLabs credits are for personal use only: nothing generated with them goes into the published film until the account has commercial rights.

**Voice (macOS, dropped).** `narrate.py` reads script A with the macOS `say` voice Daniel. It was replaced: a compact legacy voice, and no Premium voice is installed.

**Score and mix.** `score.py <narration wav44 dir> <out dir>` arranges the full-length score on the scene timeline (it imports `../../audio/synth.py`), ducks it under the voice, and writes `mix.wav`, `music.wav`, `narration.wav` and `placed.json`. Convert them with `afconvert -f m4af -d aac -b 160000`.

**Player.** `build_player.py <out dir>` writes `animatic.html`, `captions.srt` and `PACING.md` one folder up and copies the three audio files next to them.

**First live ElevenLabs test (2026-10-17, with Diede's free-tier key).** Narration (the voice Alice, British female, multilingual v2) and three sound effects worked. The key has no `user_read` or `voices_read` permission, so credits and voices cannot be read back (the test falls back to premade voices by id, and the account page is the only place to see the credits). **Music failed with HTTP 402: "Music API is not available for free users"**, so the music beds need a paid plan. The test output is in `../eleven-test/`, for listening only (personal-use credits: nothing from it goes into the published film).

**After the listening test (2026-10-17):** Diede chose the ElevenLabs voice Alice over Kokoro and accepted the whoosh and low hit. A sound effect cannot be shorter than 0.5 s (HTTP 400 below that), so a single tick is a 0.5 s generation trimmed to its first 0.15 s. Prompt that gave one click: "a single tiny click like one tap on glass, one hit only, very short, then silence" with prompt influence 0.7; "one single soft click ... no repeat" produced a buzz of twelve onsets, so check an effect by counting its onsets before using it. The whole first test cost **18 credits** by Diede's account page (narration of 181 characters and three effects), well under the estimates printed by the dry run.

**ElevenLabs music and the full animatic mix (2026-10-17, late).** After Diede topped up the account the music API works. `music-segments.json` holds one prompt per act; `generate_music.py --env-file <file> --out <dir> [--send] [--only a2-manager]` generates them (dry run by default, cached by a hash of prompt and length, `--max-credits` guard, about $0.15 per minute); `mix_eleven.py <narration wav44 dir> <music dir> <sfx dir> <out dir>` places the music segments, the three sound effects (single tick, whoosh, low hit) and the narration on the scene timeline, ducks the music under the voice and writes `mix.wav`, `music.wav`, `narration.wav` and `placed.json`; `build_player.py` then writes the player, captions and pacing report. The paid assets are kept in `../assets-eleven/`: the narration cache (copy it into a new `--out/cache` and `narrate_tts.py` serves the lines for free), the music mp3 files and the effects. The older Kokoro and synthesised-score path (`narrate_tts.py --provider kokoro`, `score.py`) still works as the free draft.
